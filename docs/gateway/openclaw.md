总结

- openclaw WS 网关：事件最丰富、lysmata 覆盖度也最高（核心事件全支持，缺 5 类边缘事件）。
- openclaw HTTP 网关：网关本身就没设计 tool/lifecycle 通道，只能拿到纯文本，是 openclaw
  一侧的协议限制，不是 lysmata 解析缺失。
- hermes：协议字段名跟 lysmata 假设不一致（toolCallId vs callId、只有 progress 一种
  event），是 lysmata adapter 解析逻辑要修。
